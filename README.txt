# Orders SQL & Power BI Analysis

End-to-end analysis of an e-commerce orders dataset.

## Tools
- SQL (SQLite / DBeaver)
- Power BI (in progress)

## Structure
- `sql/` — queries covering EDA, cohorts, RFM and Pareto analysis
- `powerbi/` — dashboard (coming soon)

## Key findings
- Beauty is the top revenue category overall
- Retention is the main pain point across all cohorts
- A small VIP segment generates a disproportionate share of revenue
- New customer acquisition is growing year over year
